# hiewLM — imported API behaviour table.
#
#   behaviour | api | strength | note
#
# `strength` is `strong` or `weak`. A weak API is one that appears in almost
# every compiled program (CRT startup, ordinary file access): it is still listed
# for context, but it does not raise the score on its own, or every Rust and
# MSVC binary would look armed. A behaviour category only scores when something
# strong lands in it.
#
# Names are matched case-insensitively, with or without a `dll!` prefix and with
# the trailing A/W dropped, so one entry covers CreateFileA and CreateFileW.
#
# Copy this file to <config>/hiewlm/rules/apis.txt to replace it wholesale.
