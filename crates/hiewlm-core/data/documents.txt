# hiewLM — document indicator table (OLE2, OOXML, RTF, PDF, VBA).
#
#   kind | value | severity | note
#
# severity is `suspicious` or `info`. Matching is case-insensitive substring.
#
# kind:
#   ole        a stream or storage name inside an OLE2 compound file
#   ooxml      a part name inside an OOXML package
#   rtf        an RTF control word or literal
#   pdf        a PDF name object or literal
#   vba-*      a VBA source keyword, grouped by what it means:
#              vba-autoexec, vba-execution, vba-download, vba-obfuscation,
#              vba-memory, vba-persistence, vba-evasion, vba-lure
#
# Copy to <config>/hiewlm/rules/documents.txt to replace it wholesale.
